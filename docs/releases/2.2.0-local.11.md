## Point Zoom

Double-click the waveform at the point you want to inspect. Each double-click
halves the visible time span, keeping that point under the pointer. Repeat for
finer inspection, down to the existing minimum span. A single click still seeks.

Select a lyric row, refine its start/end markers in the magnified view, preview
playback, then use **Apply Markers**. Zoom never changes those timestamps.
Double-click inspection temporarily holds the view rather than following
playback; pause/play or the Follow button resumes following. Explicit Follow-off
remains respected. Zoom-out and Fit controls return to a wider view.

![Marker preview and waveform controls](https://raw.githubusercontent.com/scriptusscript777/lrcget/local/editor-lrc-default/docs/screenshots/marker-preview-dark.png)

The controls and layout are unchanged; the waveform now also accepts double-click.

