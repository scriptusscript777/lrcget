# LRCGET 2.2.6+local.8

**Synced → Word timing → Loop word** repeats the selected word while you refine
its Start and End. Timing steps include 10 ms; Lead-in/Tail add listening context
without changing saved timing. Selecting another word moves the loop; phrase
Loop switches the target back to the sentence. Modes cannot compete.

Explicit word ends preserve silence gaps. Zoomed labels remain readable. Sync
Word holds selection while looping; Undo restores timing edits. Collapsing the
lane suspends repeats and retains the selected word; Stop remains available.
Reset now correctly submits an empty word list to restore estimated timings.

[Illustrated instructions](../how-to.md#loop-one-word-for-precise-timing).
