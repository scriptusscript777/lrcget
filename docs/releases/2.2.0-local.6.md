# LRCGET 2.2.0+local.6

**Editing developer: Rick Lidgett** ([@scriptusscript777](https://github.com/scriptusscript777)).
An independent local build based on upstream LRCGET 2.2.0. Original project
credits and MIT license are preserved. This is not an official upstream release.

## Download and Install

[Download the Linux amd64 Debian installer](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.6/LRCGET_2.2.0%2Blocal.6_amd64.deb).
Close LRCGET normally before upgrading so unsaved edits are preserved.

```bash
sudo apt install ./LRCGET_2.2.0+local.6_amd64.deb
```

This upgrades the existing LRCGET installation, rather than adding another app.
The package is unsigned. Its SHA-256 is:

```text
3d64b2cdd7f78f818fb98d0e8a461f6c8b5457774550f554abc9a4525ea6e27b
```

Only the Linux amd64 Debian build is provided here. Windows/macOS builds have
not been tested for these modifications. Upstream's Linux distribution guidance
applies (Ubuntu 24.04+ / Linux Mint 22+).

## New Editing Controls

![Light theme: synchronized editing and timing steps](https://raw.githubusercontent.com/scriptusscript777/lrcget/v2.2.0-local.6/docs/screenshots/editor-light.png)

1. Open a track's lyrics editor and select **Synced**.
2. Select a lyric line. Choose **Timing step**: 10, 25, 50 or 100 ms.
3. Use the line's earlier/later controls to move the line and its word/end
   timestamps together. End-only controls adjust the ending independently.
4. Use the undo/redo arrows to reverse changes. Ctrl/Cmd+Z undoes;
   Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y redoes. Text fields retain native text undo.

Undo includes deleted lines, blank cues and word timing. Up to 100 synced edits
are retained in the current session; history does not survive closing the editor.

## Loop a Phrase

![Dark theme: readable timing options and looping controls](https://raw.githubusercontent.com/scriptusscript777/lrcget/v2.2.0-local.6/docs/screenshots/editor-dark.png)

1. Select a line with valid start/end timing. The next line's start can supply
   an ending when an explicit end is absent.
2. Set **Lead-in** and **Tail** context, each from 0 to 5 seconds.
3. Click the repeat icon to enable looping, then click it again to stop looping.
4. Pause to pause listening. Selecting another line or switching to **Plain**
   disables the loop.

Looping follows playback updates; it is not sample-accurate. Fine adjustment
controls do not automatically prove synchronization with a singer.

## Export Sidecars and Embedded Lyrics

![Export menu: synced LRC and embedded lyric targets](https://raw.githubusercontent.com/scriptusscript777/lrcget/v2.2.0-local.6/docs/screenshots/editor-export.png)

1. For embedding, open **Configuration > Experimental** and enable
   **Enable embed lyrics option**. Keep independent backups of your library.
2. In the editor, open the arrow next to **Save**.
3. Select **Synced lyrics (.lrc)**, **Plain lyrics (.txt)** and/or
   **Embed into track**, then click **Save and export**.
4. **Save** alone saves to the application database. **Save and Publish** is a
   separate, explicit upload to your configured LRCLIB instance; normal saving
   and exporting do not publish lyrics.

Synced LRC starts selected. Embedding follows the saved preference and the
experimental gate. MP3 writes replace stale USLT/SYLT variants using ID3v2.4,
UTF-8 and millisecond SYLT timing. FLAC uses its existing lyric comments.
Artwork and unrelated metadata are retained; audio is not re-encoded.
Words and supplied timing are not automatically rewritten by export.

## File Safety and Refresh

- TXT and LRC files coexist; exporting one no longer deletes the other.
- Exports are prepared in a temporary sibling file and replaced only after
  preparation succeeds. Existing destinations retain one rolling backup named
  `<filename>.lrcget.bak`, containing the previous version.
- Embedded export stages and backs up the complete audio file. Allow disk space
  for both extra copies. Backups are not automatically deleted or uploaded.
- Read-only, symlink and non-file destinations are refused. Detected external
  changes during staging abort export; this is not a cross-application file lock.
- Saves preserve edits made while the backend is writing.
- Startup and **F5 / Refresh library (F5)** run an incremental library scan.
  Active scans and open dialogs prevent overlapping refreshes. Incomplete scans
  do not prune missing tracks.
- Refresh does not export or overwrite externally edited LRC files. Imported
  lyrics remain database-owned; use an explicit import/export workflow.

To restore a rolling backup, close the application, keep a separate copy of the
current file, and restore the backup to the original filename.

## Verification and Limitations

- 170 frontend tests and 40 Rust tests passed.
- Frontend lint: zero errors, with existing warnings.
- Release compilation and Debian packaging passed.
- Isolated Linux desktop tests verified startup/F5 discovery and removal.
- Browser UI checks verified undo/redo, steps, looping commands and light/dark
  contrast. Screenshots use temporary test lyrics and a mocked backend, not a
  personal music library; they do not demonstrate acoustic alignment.

Embedded-lyric display depends on the player. This release does not guarantee
lyrics in every car stereo, older Windows player or Jellyfin client.
