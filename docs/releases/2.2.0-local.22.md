# LRCGET 2.2.0+local.22

Clicking the waveform starts playback from the selected point, including when
paused or stopped. Play resumes the loaded recording without reloading it or
briefly moving the playhead to zero. Older position updates received during a
seek cannot overwrite the selected point while the audio thread acknowledges it.

Double-click zoom and zoom buttons preserve playback time. Single clicks wait
350 ms to distinguish them from double-click zoom. The moving playhead uses a
short linear transition, respects reduced-motion settings, and follows the
existing Follow control. Keyboard inspection keeps its existing paused behavior.

Validation: all 380 frontend tests passed, as did scoped ESLint, Prettier,
Cargo check and production Debian packaging. Native desktop checks in an isolated
profile verified click playback from stopped/paused states, playhead advancement,
pause stability, zoom continuity and resume without a zero jump. Ruff reports
11 existing findings in the unchanged Python fake-music generator; no Python
code changed. Existing compiler and bundle-size warnings remain.

Close LRCGET, then install:

```bash
sudo apt install /home/rick/Downloads/LRCGET_2.2.0+local.22_amd64.deb
```

The accompanying `.sha256` file verifies the installer.
