# 2.2.7 — Word Sync confirmation and additional Pause/Resume

- Confirming manual divider or Start/End timing turns Sync Word gray/disabled
  until another timing adjustment. Repeated clicks/hotkeys cannot overwrite it.
- Playback, same-word reselection and unchanged precision values do not unlock
  confirmation. Changed word timing/selection/bounds are reevaluated.
- Ordinary Sync-and-advance remains available, with unchanged duplicate stamps
  suppressed quietly rather than producing a misleading range warning.
- Add a separate Pause/Resume control beside word-lane Play. It retains playback
  position and word/phrase loop state; Play keeps its replay behavior.
- Preserve sentence markers, Undo/Redo and independent TXT/LRC/ELRC workflows.

See [illustrated how-tos](../how-to.md#edit-individual-words) and the
[review/package status](../reviews/2.2.7.md). Debian-only update using the main
version number. AppImage, Windows, GitHub publication and creator notification
remain deferred.
