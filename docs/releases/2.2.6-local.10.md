# 2.2.6+local.10 — safe word timing (Debian)

- Word boxes edit timing only; wording belongs to sentence rows.
- Drag selects its divider and preserves both sentence markers. The next Sync
  retains a manual drag/precision edit instead of stamping stale playback.
- Unsafe Sync positions are rejected without moving/collapsing neighbors or advancing.
- Accepted/rejected updates, pointer refreshes, active-drag shortcuts and Delete
  are guarded. Undo/Redo restores timing edits. Zoom and word Loop remain supported.
- Document word validation rejects unordered, collapsed and overlapping intervals.
- Export snapshots track identity before Save; LRC import rejects invalid seconds.
- TXT/LRC/ELRC remain independently selectable, with normal safe replacement and
  no invented word timing. Enhanced import retains starts, ends and silence gaps.

See the [review and package status](../reviews/2.2.6-local.10.md) and
[illustrated workflow](../how-to.md#edit-individual-words).
AppImage/Windows updates, GitHub publication and creator notification are deferred.
