# LRCGET 2.2.0+local.10

Editing developer: **Rick Lidgett** (@scriptusscript777).
Independent fork release; original authors and license remain credited.

## Playback Following and Fixed Markers

- Zoom no longer turns playback following off. With Follow enabled, the
  waveform advances as the moving playhead reaches a zoomed window boundary.
- Wheel/trackpad and bottom-pan inspection still hold the view rather than
  snapping back. Pause/play resumes following after manual inspection.
- Explicitly switching Follow off keeps it off across playback restarts.
- Marker timestamps remain fixed after you place/edit them, during playback,
  zooming and scrolling. Off-screen markers retain their recording positions.
- Drag mapping stays fixed until release/cancel.

## Preview Then Confirm

- Dragging and keyboard nudges stage local marker previews without changing
  the lyric document. Listen, scroll and zoom before committing.
- **Apply Markers** commits the start/end pair as one undoable change.
- **Cancel** discards the pair. Escape cancels a drag, or the pending preview
  when no drag is active. Switching phrases or closing discards pending previews.
- Start edits translate word timings once; end edits cannot truncate words.
- Save/export remains separate and uses confirmed timings, never pending previews.

No lyric/audio files are rewritten by navigation. This corrects the .9 behavior
that disabled follow when magnifying a selected phrase. All precision controls,
light/dark styling and export features remain available.

[Editing guide](https://github.com/scriptusscript777/lrcget/blob/local/editor-lrc-default/docs/editing-guide.md)

## Text and Timed Lyrics Import

The header's **Import lyrics file** action accepts plain `.txt`, line-timed
`.txt` and `.lrc`. Untimed text becomes synced rows without invented timestamps;
listen and set each line's start/end. Timed files retain their line timestamps
for refinement. Import never rewrites the source TXT/LRC file. Replacing existing
words/timings in the open editor requires confirmation; Cancel keeps them intact.
Empty/malformed files do not change the document. Enhanced word tags and nonzero
LRC offset headers require conversion to explicit line timestamps first.

## Install

[Linux amd64 installer](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.10/LRCGET_2.2.0%2Blocal.10_amd64.deb)
and [checksum](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.10/LRCGET_2.2.0%2Blocal.10_amd64.deb.sha256).

Close LRCGET, then install the unsigned Linux amd64 package:

```bash
sha256sum -c LRCGET_2.2.0+local.10_amd64.deb.sha256
sudo apt install ./LRCGET_2.2.0+local.10_amd64.deb
```

This upgrades the existing app. No Windows/macOS build is supplied.
