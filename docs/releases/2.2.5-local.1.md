# LRCGET 2.2.5+local.1

**Loop stays on while navigating within the recording.** Selecting or playing
another lyric moves repetition to that lyric's start/end markers. Sentence Play,
word playback, timing auditions, pause/resume and waveform zoom preserve the
mode. Turn **Loop selected phrase** off explicitly for continuous playback.
Waveform seeking uses the current selected range without selecting another lyric.

Untimed/reversed selections suspend repetition without clearing the toggle.
A short conditional message explains unavailable boundaries, and the active Loop
button remains usable so you can turn it off. Plain/instrumental states suspend
repetition; returning to a valid Synced selection resumes it. Changing recording,
closing the editor and genuine playback failures still reset safely.

Navigation invalidates delayed starts/replays and failures from an earlier lyric,
preventing a late resume from seeking backward to the previous selection.
Markers, lyric timing, saved data and exports are unchanged by navigation.

## Checks

396 frontend tests passed, including new cases for mode retention, invalid-range
suspension, usable Off controls, inactive tabs, delayed navigation and stale
failures. Browser checks verified actual UI retargeting/repetition, zoom without
seeking, tab suspension/restoration and explicit Off without saving lyrics.
Native WebKitGTK checks verified selection, marker time, zoom, tab restoration
and Off in an isolated profile. Scoped ESLint has no errors and one existing
unused-import warning; Ruff reports 11 existing findings in unchanged Python.
Rust logic is unchanged from 2.2.4's 57 passing tests (one optional fixture ignored).
See the [review](../reviews/2.2.5-local.1.md).

## Upgrade

This package upgrades the existing `lrcget` app with its same identifier and data
location. Linux amd64 requires glibc 2.39+, GTK 3 and WebKitGTK 4.1.

```bash
sha256sum -c LRCGET_2.2.5+local.1_amd64.deb.sha256
sudo apt install ./LRCGET_2.2.5+local.1_amd64.deb
```

Production Debian packaging and checksum verification passed. APT simulation
confirms one upgrade from 2.2.4, with zero new apps and zero removals.
The focused [upstream proposal](https://github.com/tranxuanthang/lrcget/pull/427)
adds the core Loop feature independently and passed 166 frontend tests.

Read the [loop how-to](../how-to.md#loop-between-the-markers),
[complete reference](../editing-guide.md#persistent-loop-navigation-225) and
[feature overview](../app-overview.md). Other Linux package formats remain paused.
