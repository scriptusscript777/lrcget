## Marker Visibility and Editing Help

- One vertical guide per marker. Separate top/start and bottom/end handles stay
  visible and clickable even when their timestamps are very close.
- Resyncing an off-screen start reveals it without losing magnification.
- Compact themed hover/focus help explains timing, playback, word editing and
  waveform controls. Tooltips wrap instead of stretching across the window.
- A live `mm:ss.mmm` readout shows playhead position. Player events arrive every
  40 ms; this display does not promise 1 ms audio-device accuracy.
- Only Loop bounds the displayed cursor while the repeat seek completes.
  Normal Play continues forward. Lead-in/Tail can extend the loop range;
  zero values repeat strictly between the markers.
