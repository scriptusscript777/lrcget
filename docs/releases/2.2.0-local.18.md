## Native Hover Descriptions

- Hover an editing control to see its standard button description.
- The browser controls the delay; a fixed two-second delay is not promised.
- Editing help creates no popup panels, overlay elements or focus triggers.
- Save and Debug also use native descriptions, not popup panels.
- Interactive menus, themes, markers and Loop behavior remain unchanged.
