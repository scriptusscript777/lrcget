# LRCGET 2.2.6+local.6

**Word preview** reads along with highlighted words while timing boxes stay
collapsed. The toggle enables Follow Lyrics. Existing Loop holds the selected
phrase, rewinds the highlight with playback and stays on until disabled. Word
ends clear highlights in gaps. Preview does not edit, resize, save or export;
unsaved evenly spaced estimates are labeled.

![Word preview, light](../screenshots/current/word-playback-preview-light.png)
![Word preview, dark](../screenshots/current/word-playback-preview-dark.png)
![Loop and timeline zoom](../screenshots/current/word-preview-loop-zoom-light.png)

Configuration now labels the saved opt-in **Embedded lyrics → Enable embedded
lyrics**. MP3 writes standard UTF-8 ID3v2.4 USLT/SYLT. Selecting ELRC and Embed
together also writes ELRC text in a separate described USLT and custom TXXX
`LYRICS_ELRC`, and uses word timestamps in SYLT. Normal plain USLT remains.
Custom-field/player recognition varies; legal text storage does not guarantee
karaoke playback. FLAC retains its Vorbis lyric comments.

Native tag editing preserves comment languages, descriptions, artwork and
unrelated custom fields. Missing ID3v2 tags are created. Written lyrics are
verified before atomic replacement; invalid text/timing leaves the MP3 unchanged.
TXT, standard LRC and ELRC sidecars remain independent.

![Embedded lyrics settings](../screenshots/current/embedded-lyrics-settings-light.png)

Kiss Me Goodbye and Joseph originals were inspected without changing them. Both
had valid line-level lyric frames. Writes on copies pass independent Mutagen
checks; compressed audio hashes match the originals. Synthetic word timing was
used only on additional copies to verify Enhanced embedding, not to invent
karaoke timing for the songs.

Validation: 420 frontend tests, 73 normal Rust tests and one separately invoked
real-file audit passed. Browser checks verify gaps, Loop rewinds, collapsed boxes,
zoom and Configuration wording. Cargo check, changed-file ESLint and production
Debian packaging pass. Existing Ruff findings in the unchanged Python utility
are recorded in the [review](../reviews/2.2.6-local.6.md).

See [word preview instructions](../how-to.md#review-words-without-resizing-timing-boxes)
and [embedding details](../how-to.md#embed-standard-and-enhanced-lyrics-in-mp3).
