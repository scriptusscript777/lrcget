# 2.2.6+local.9 — server word timing and enhanced import

- Search identifies valid word-timed YAML records and optionally filters for them.
- Ordinary LRC and plain text fall back automatically without invented word timing.
- Raw server word data is retained by download/apply/prepare/refresh and publication.
- TXT/LRC/ELRC import supports independent format workflows, word ends and gaps.
- Word preview stops highlighting at explicit ends. Stale search data clears on failure.
- TXT, LRC and ELRC save selections remain independent and remembered.

Checks and package validation are recorded in the [review report](../reviews/2.2.6-local.9-release.md). GitHub publication
and Windows MSI revalidation remain pending until the release workflow succeeds.
This does not add automatic singing alignment, automatic ELRC library scanning,
or word highlighting to Jellyfin web.
