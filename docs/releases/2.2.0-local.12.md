## Loop Between the Markers

Phrase loops now use pending marker previews before you apply them. Drag/release
or nudge a marker, enable **Loop selected phrase**, listen and refine, then use
**Apply Markers**. **Cancel** restores committed loop boundaries. Dragging itself
does not repeatedly reseek audio. Previews never save or export without Apply.

Lead-in and Tail default to zero for an exact marker-to-marker loop. Increase
them only when you want listening context. Invalid/stale previews cannot move
another lyric's loop. Changing selected lines turns looping off.

Close LRCGET, then install the Linux amd64 package:

```bash
sudo apt install ./LRCGET_2.2.0+local.12_amd64.deb
```
