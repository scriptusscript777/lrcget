## Initial Sentence Markers

Entering Synced selects the first timed lyric if there is no existing selection,
skipping opening blank cues and untimed rows. Its waveform markers show the
sentence's start and end. Selecting another sentence changes the marker target;
returning from Plain preserves your selection. Untimed rows remain editable
without invented timestamps or markers. Selection does not create history edits.
After assigning an untimed sentence's start, its provisional end is labeled
**Inferred end** until you confirm it. Source text files remain untouched.

[Complete editing guide](https://github.com/scriptusscript777/lrcget/blob/local/editor-lrc-default/docs/editing-guide.md)

Sentence start/end sync and nudge controls update markers from the same shared
document. Editing keeps the target fixed; Follow Lyrics selects each playing
sentence's boundaries without rewriting timing. Word sync preserves existing
sentence lead-in unless the first word moves. Tooltips explain the distinction.
Bounds checks reject reversed timing, truncated words and changes outside the
recording. Syncing uses only the correct recording's playback, including files
without duration metadata. Failed sync-and-advance shortcuts do not skip a line.
Pending replay actions cannot seek a different recording or a subsequently
edited lyric. Track switches and document changes no longer leave stale marker
previews or prevent playback-follow updates.
