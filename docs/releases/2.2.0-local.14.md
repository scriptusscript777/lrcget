## Follow Lyrics and Edit Words

- Word boxes advance to the current lyric during ordinary playback, including
  backward seeks. Follow Lyrics is enabled initially; selecting a row pins it.
- Loops, marker previews, word drags and text edits hold the selected lyric so
  playback cannot switch away from work in progress.
- Select a box and use Edit word, F2 or right-click to correct its wording.
  Enter/check applies; Escape/cancel discards. Undo/Redo includes the correction.
- Word corrections preserve all timestamps and token whitespace. Empty,
  multi-token and stale drafts are rejected; split/merge remain explicit.
- Plain and Synced remain independent working versions. Import sources are
  not overwritten. Save/export remain explicit actions.
- Compact controls support light and dark themes without adding another panel.

## Install

Close LRCGET, then install the Linux amd64 package:

```bash
sudo apt install ./LRCGET_2.2.0+local.14_amd64.deb
```
