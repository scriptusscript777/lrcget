# LRCGET 2.2.0+local.9

Editing developer: **Rick Lidgett** (@scriptusscript777).
Independent fork release; original authors and license remain credited.

## Waveform Zoom and Scrolling

- Scroll over a zoomed waveform using a mouse wheel or horizontal trackpad
  gesture, or use the bottom pan control to reach either phrase marker.
- Manual scrolling disables playback follow so the view stays where you edit.
  Click the existing crosshair follow button to resume automatic paging.
- Magnification prioritizes the selected phrase instead of an unrelated
  playhead and keeps a visible start/end marker in view. Zooming a selected
  phrase also disables follow.
- Navigation cannot change the waveform mapping during a marker drag.
- Panning/zooming never changes lyric timestamps or writes music files.
- Marker dragging uses the magnified scale and preserves the grab offset;
  keyboard nudges retain the selected 10/25/50/100 ms step. A drag commits
  once and is undoable. Navigation is not a proof of acoustic alignment.

All .8 editing features remain. No additional decoder or AI model is required.
The interface and light/dark theme styling are unchanged.

## Install

[Linux amd64 installer](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.9/LRCGET_2.2.0%2Blocal.9_amd64.deb)
and [checksum](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.9/LRCGET_2.2.0%2Blocal.9_amd64.deb.sha256).

Close LRCGET and install the unsigned Linux amd64 package:

```bash
sha256sum -c LRCGET_2.2.0+local.9_amd64.deb.sha256
sudo apt install ./LRCGET_2.2.0+local.9_amd64.deb
```

This upgrades the existing application, not a second copy. No Windows/macOS
build is supplied for this fork release.
