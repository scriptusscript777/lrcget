# LRCGET 2.2.0+local.21

Startup and F5 detect a matching external LRC even when the recording has not
changed. A valid LRC upgrades missing or Plain lyrics to Synced, using its words
instead of a matching TXT. If no valid LRC exists, a matching TXT fills missing
lyrics. Untimed/empty LRC files cannot mark a song Synced.

Saved synced lyrics, instrumental records and explicit editor-save dates remain
protected. Refresh never rewrites recordings or sidecar files. Further external
changes to an already synced song require explicit import.

Validation: 54 Rust tests passed, with one optional waveform fixture test ignored.
Restart detection and fallback behavior are covered with both hash and metadata
scans, including unchanged audio and conflicting external edits. Cargo check and
production Debian packaging passed. A native desktop test confirmed startup
upgrades Plain to Synced while MP3/TXT/LRC hashes stay unchanged; current
light/dark screenshots show the result. Ruff reports the same 11 existing
findings in the unchanged Python fake-music generator; no Python code changed.

Close LRCGET, then install the new local package:

```bash
sudo apt install /home/rick/Downloads/LRCGET_2.2.0+local.21_amd64.deb
```
