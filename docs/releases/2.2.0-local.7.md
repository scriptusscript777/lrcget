# LRCGET 2.2.0+local.7

**Editing developer: Rick Lidgett** ([@scriptusscript777](https://github.com/scriptusscript777)).
This independent build adds a waveform to the lyrics editor. Original LRCGET
credits and the MIT license remain unchanged; this is not an official upstream release.

## Download and Install

[Linux amd64 Debian installer](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.7/LRCGET_2.2.0%2Blocal.7_amd64.deb)
and [SHA-256 checksum](https://github.com/scriptusscript777/lrcget/releases/download/v2.2.0-local.7/LRCGET_2.2.0%2Blocal.7_amd64.deb.sha256).
Close LRCGET normally before upgrading to preserve unsaved edits.

```bash
sha256sum -c LRCGET_2.2.0+local.7_amd64.deb.sha256
sudo apt install ./LRCGET_2.2.0+local.7_amd64.deb
```

This upgrades the existing installation, not a second app. The installer is
unsigned. Only Linux amd64 is provided/tested here; Windows/macOS installers
are not included. Upstream's Ubuntu 24.04+ / Linux Mint 22+ guidance applies.
The waveform needs no additional tool installation or WAV conversion.

## Waveform Editing Aid

![Waveform in the synchronized lyrics editor](https://raw.githubusercontent.com/scriptusscript777/lrcget/v2.2.0-local.7/docs/screenshots/waveform-light.png)

1. Open a track's lyrics editor. Its waveform appears below the existing player.
2. Click the waveform to seek. The playback cursor follows the same player,
   including speed changes and phrase looping.
3. Use the magnifier controls to zoom in/out and the fit icon to show the whole
   track. Zoom centers around the visible cursor, otherwise the view midpoint.
4. When zoomed, use the horizontal range control to pan to another section.
5. Focus the waveform and use Left/Right to seek by 100 ms, Shift+Left/Right by
   five seconds, or Home/End for the track boundaries.

Paused waveform seeking stays paused. No extra play/pause or looping controls
are added. Existing timing steps, undo/redo, saving and exports remain available.
Seeking does not edit lyric text or timestamps; save/export stays explicit.

![Zoomed waveform with horizontal panning](https://raw.githubusercontent.com/scriptusscript777/lrcget/v2.2.0-local.7/docs/screenshots/waveform-zoom.png)

## Performance and Safety

- Existing Symphonia decoding produces bounded peak data on a background worker.
  There is no second playback engine, Whisper/Demucs pass or permanent WAV file.
- The first preview decodes once; subsequent openings reuse cached peaks.
  Playback, zoom, panning and theme changes do not decode again.
- File size/modification-time changes invalidate the cache, including tag edits.
  Changes preserving both values are not detected. At most 128 previews are
  cached, with 24,000 peak bins each; audio up to four hours is supported.
- Peak extraction is read-only. Missing/unsupported audio shows an error/retry
  state without blocking lyric editing or the existing player controls.
- Late responses, queued seeks and observers are guarded during source changes
  and editor closing. Newly loaded audio cannot be restarted by a stale stopped
  player-state event during waveform seeking.

The waveform shows the entire mix, not just vocals. It helps manual listening
and timing edits; it does not prove vocal boundaries or automatically align lyrics.
Long-recording peak bins may be coarser than the 10 ms timing control.
