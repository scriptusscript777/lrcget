# LRCGET 2.2.6+local.4

Pending waveform marker edits now change **only the original sentence Sync button
color** to amber. The buttons keep their usual Equal icon, circular shape and
24px size. No Confirm text is displayed. Applying or cancelling the marker edit
restores the ordinary color. Each button responds only to its corresponding
start/end preview; direct playback Sync behavior is unchanged.

Cancel, F1 help, saved overlap protection and the cleaner Word Timing header remain
as described in [local.3](2.2.6-local.3.md). Enhanced LRC export is not added.

its app identifier and data location. Updated source, docs, screenshots, installer
