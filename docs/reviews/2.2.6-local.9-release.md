# Word-timed integration review — 2.2.6+local.9

Control-flow review covered search normalization/filtering, preview/playback,
server payload resolution, import replacement/undo and independent save formats.
Stale legacy content no longer overrides server YAML in search; failed searches
clear old results; failed settings loads retain defaults. Word preview honors
explicit word ends rather than carrying a highlight through gaps. Malformed
nonempty structured download data errors before replacing saved lyrics.

## Verified checks

- 459 frontend tests passed; scoped ESLint has no findings.
- 76 native tests passed, 2 existing ignored tests; cargo check passed.
- Three Windows MSI version/identity configuration checks passed on Linux.
- Real Vue search/filter/apply/preview checks passed with temporary mocked data,
  including ordinary LRC/plain fallback and failed-search cleanup.
- Real editor ELRC import/replacement restores editable word starts, ends and gaps.
- Existing single-word loop, precision edits, padding, zoom, Undo, settings and
  read-only preview checks passed. Fresh light/dark captures document the changes.
- Local documentation references checked without broken targets.

## Existing limitations and release gates

Ruff reports 11 existing findings in unchanged tools/generate_fake_music.py.
No Python source was changed. Existing build warnings concern Browserslist age,
large frontend chunks, a Cargo cfg dependency warning and proc-macro-error2's
future compatibility. These are not introduced by this update.

Windows revalidation and MSI install/reinstall/uninstall remain pending. The first
Windows run built a diagnostic MSI but failed tests due to missing FFmpeg and a
Unix-specific test path; corrected setup remains local. No Windows 11 desktop
or previous-version upgrade verification is claimed. GitHub release publication
and creator notification remain pending this validation gate.

Enhanced import rejects nonzero offsets, ambiguous repeated line tags with absolute
word timing, malformed ranges and out-of-order rows. It does not add automatic
ELRC library scanning or automatic singing alignment. Standard LRC does not
carry word times; keep ELRC/internal data to retain them.

The local.9 Debian package has matching `lrcget`/amd64 identity and a higher
version than installed local.8. PackageKit installation could not obtain
administrator authentication, and noninteractive sudo is unavailable. The
installed app remains local.8 until the user runs the documented apt command.

The extracted Debian executable opened its actual native window with an isolated
temporary profile. Its checksum, package identity and version ordering passed.
This is a startup check, not a successful administrator installation.

Debian and AppImage production bundling completed successfully. AppImage SHA256
and actual native startup passed using a separate temporary profile. The current
source ZIP, tar.gz and Windows source ZIP are supplied separately from installers.
