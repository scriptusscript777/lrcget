# 2.2.6+local.1 review

Verdict: APPROVE. No unresolved critical or high-priority findings in the change.

## Behavior and fixes

Live marker bounds drive sentence highlighting without changing its colors.
Sentence Sync confirms one corresponding moved boundary, using playback for an
unchanged boundary. Deferred restoration preserves only the other pending marker
and checks line identity/index. Cancel returns to the last confirmed baseline.
Untimed text has provisional markers and requires confirming Start before End.

Review caught and fixed a selection race: a row selects then Syncs before waveform
props update. Expected line identity/index prevent the previous sentence's draft
being applied to the new row. Failed nudges now return false without triggering
an audition. Bulk timing shifts validate the proposed batch atomically, including
neighbor overlaps. Sync-and-advance uses the confirmed start to close the previous
sentence instead of a different playback position when a marker was chosen.

Default-on overlap protection is scoped to the editor session. Imported existing
ranges are preserved; intentional overlap requires turning protection off.
Loop receives released/nudged preview bounds while sentence highlight receives
live drag bounds, avoiding repeated seek commands during pointer movement.

Frontend/backend LRC converters preserve confirmed gaps of at least 250 ms and
final ends with standard empty timestamped cues. Duplicate timestamps, short-gap
flicker and clearing another active overlapping lyric are avoided. Internal
optional start fields support untimed rows/words without inventing timestamps;
lyrics-presence flags distinguish untimed text from synced content.

## Limits and rollback

No Jellyfin server/client playback integration was run. Export uses standard LRC;
blank-cue display depends on the player. Exact ends for gaps under 250 ms remain
internal and cannot be recovered from LRC alone. Existing blank cues are preserved.

GitHub publishing and creator notifications are paused. Source work is committed
locally and backed up to Rick's existing local Git server. The previous 2.2.5
installer remains available; reverting source and downgrading the same package
can restore the previous UI without creating another installation.
