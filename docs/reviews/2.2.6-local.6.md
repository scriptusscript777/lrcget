  scrolls only its own text view. It emits no timing edits or playback seeks.

## Standards and practical limits

[ID3v2.4 frames](https://id3.org/id3v2.4.0-frames) define USLT, SYLT and TXXX;
[structure rules](https://id3.org/id3v2.4.0-structure) allow UTF-8 and unknown
language XXX. ELRC in USLT/TXXX is plain text storage. `LYRICS_ELRC` is an app
convention, with no promise that a particular player reads it. SYLT uses binary
word/line timestamps. Existing songs do not acquire accurate word timing without
actual word editing. Sidecar Enhanced LRC import and Jellyfin web karaoke are
outside this update. GitHub publication remains paused.
