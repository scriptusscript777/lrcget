# Word Sync lock and word-lane Pause/Resume review — 2.2.7

The previous manual-adjustment flag was consumed on the first Sync, allowing a
second press to stamp an unrelated playback position. Confirmed manual timing
is now keyed by sentence/index, word signature and bounds. The UI grays/disables
Sync, and the underlying action also blocks shortcuts. Another real adjustment
invalidates confirmation; unchanged numeric values, playback and same-word
reselection preserve it. Word/document/bounds changes are reevaluated.

Normal Sync retains advance and safely suppresses duplicate unchanged-position
actions. Rejected updates cannot advance. Manual confirmations retain selection.
The added Pause/Resume button delegates through the synced editor to existing
player functions. It does not seek, replay, edit lyrics or toggle Loop; existing
Play still replays. Drag-time pause/resume is disabled to keep pointer geometry
and audition state stable. Both controls use matching-source playback status.
