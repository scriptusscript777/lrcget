# Complete documentation and packages review — 2.2.6+local.8

## Scope

The app feature code remains the reviewed local.8 editor/export implementation.
This update adds a manual native Windows build workflow and disposable-runner MSI
checks, refreshes the guides/images, and supplies source archives alongside packages.
No personal music or live lyrics database was used for validation. Original
authors/license remain credited. No automatic word alignment feature was added.

## Logic and code review

- Workflow is manual, read-only to repository contents, and checks command failures.
  It builds native MSVC/WiX rather than relabeling a Linux executable as Windows.
- Standalone MSI builder uses locked dependencies, a validated version overlay and
  stable x64 upgrade identity, cleans only stale target MSI outputs, requires one
  fresh package and produces SHA256. Its temporary config is cleaned on failure.
- MSI installation checker refuses personal/non-Windows environments, validates
  the hash before installation, checks installer exit codes, writes verbose logs
  and removes its installed test product in a finally block. Tests run only on a
  disposable CI runner. Same-version reinstall is not an older-version upgrade test.
- Diagnostic artifacts may exist after a failed workflow; release publication must
  require successful checks rather than treating artifact existence as success.
- Documentation distinguishes existing sequential Sync word from word-loop refinement,
  Reset estimates from measured timings, and standard LRC from optional ELRC exports.
  ELRC re-import and the reported first-word label issue are not claimed fixed.
- Existing upstream PRs remain unchanged; notification can reference the established
  fork-editor issue rather than create overlapping editor-port proposals.
