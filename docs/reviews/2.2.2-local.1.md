# Code Review

**Verdict:** APPROVE
**Confidence:** HIGH

## Summary

Reviewed the marker helper/component, parent neighbor wiring, playback composable,
callers and regression tests. Boundary warnings are derived from live preview
values without blocking intentional overlaps or mutating adjacent lyrics.

## Findings and implemented improvements

The final lyric previously had an inferred waveform end but no usable Loop end.
Loop now falls back to a finite positive recording duration when no next start
exists. Unknown duration remains unavailable. Explicit and preview ends retain
priority, and source/selection/disposal guards remain unchanged.

Warnings skip untimed/malformed neighbor boundaries, distinguish equality from
crossing, and use the saved current start for an inferred previous end. Their
distances describe boundary crossings even if a marker moves entirely past a
neighbor. The display is conditional and wraps under the toolbar. It does not
add confirmation, change playback/zoom, or interfere with marker hit areas.
Cancel/selection changes use existing draft cleanup; Apply retains the one-edit
history path and word/audio bounds. No new blocking defects found.
